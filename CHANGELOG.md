# Changelog
Historial de modificaciones del orquestador de infraestructura raíz.

## [0.1.1] - 2026-06-15
### Added
- Incorporación de llamadas remotas a módulos desacoplados de GitHub (`vpc`, `ec2`, `storage`) utilizando tags semánticos estables (`v0.1.1`).
- Implementación nativa de Application Load Balancer (ALB) y Target Group acoplado a la capa de cómputo modular.
- Pipeline de GitHub Actions para validación y análisis sintáctico de la raíz.

## [1.0.0] - 2026-05-28
### Added
- Estructura monolítica inicial de la Evaluación 2.
